## 📘 Deskripsi

**Aplikasi Penentuan Dosen Pembimbing** merupakan sistem pendukung keputusan yang dirancang untuk membantu jurusan atau program studi dalam menentukan dosen pembimbing berdasarkan kriteria tertentu seperti kuota, keahlian, kesesuaian topik, dan pengalaman.

Metode yang digunakan adalah **Weighted Product (WP)**, salah satu metode perhitungan dalam Sistem Pendukung Keputusan (SPK) berbasis pembobotan dan perankingan.

---

## 🚀 Fitur Utama

✅ Input dan kelola data mahasiswa  
✅ Input dan kelola data dosen  
✅ Penentuan pembimbing otomatis berdasarkan WP  
✅ Penentuan kriteria dan bobot penilaian  
✅ Perhitungan nilai preferensi  
✅ Hasil ranking dosen terbaik per mahasiswa  
✅ Tampilan hasil yang interaktif & dapat diekspor
